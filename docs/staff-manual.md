# 店舗スタッフ向け 管理画面操作マニュアル

## このマニュアルについて

このマニュアルは、店舗スタッフが管理画面で注文や商品を確認・登録するための手順書です。画面に表示されている項目名やボタン名をそのまま使って説明しています。

画面の配置や内容がこの説明と違う場合は、無理に操作を続けず、店舗の管理担当者に確認してください。

> ⚠️ **管理担当者への確認が必要なこと**
>
> 送料・代引手数料の金額、入金確認、顧客への連絡方法、商品の公開判断などは、画面だけでは決められません。このマニュアルでは金額や店舗独自のルールを決めていません。担当者から確認した内容に従ってください。

## 1. 管理画面を開く

1. 管理画面のURLを開きます。管理画面の入口は `/admin` です。
2. ログインしていない場合は、ログイン画面でスタッフ用アカウントの情報を入力します。
3. 管理画面が表示されたら、メニューから作業したい項目を選びます。

管理メニューには、次の項目があります。

- ダッシュボード
- 注文管理
- 商品管理
- FAX注文書管理
- お知らせ管理
- 顧客台帳
- WEB会員管理
- ショップを見る

スマートフォンでは、画面上部のメニューボタンを押すと管理メニューが開きます。

**【画面キャプチャ C01 をここに挿入】**

> 📷 **撮影する画面：** 管理画面のダッシュボード  
> **撮影状態：** ログイン直後。PCでは管理メニューが見える状態、スマートフォン用の説明も作る場合はメニューボタンを開いた状態も別に撮影します。  
> **写す項目：** 管理メニュー、注文件数のカード、商品情報の最終更新日時。注文データはテスト用の架空データを使います。

> ⚠️ 管理画面を開けない、または「アクセスできません」と表示された場合は、アカウントの権限がない可能性があります。別のアカウントを試さず、管理担当者に連絡してください。

## 2. 注文を検索して確認する

### 注文一覧を開く

1. 管理メニューの「注文管理」を選びます。
2. 注文一覧で、必要に応じて検索条件を入力します。
3. 「検索」を押します。条件を消して最初から検索する場合は「クリア」を押します。
4. 該当する注文の「詳細」を押します。

### 検索に使える項目

| 項目 | 入力方法 |
| --- | --- |
| 注文番号 | 注文詳細に表示される番号を入力します。番号が分かる場合に使います |
| 注文者氏名 | 氏名の一部でも検索できます |
| 注文日 | 必要なら開始日と終了日を入力します |
| ステータス | 「すべて」または状態を選びます。「対応中」は受付・入金待ち・発送準備中です |

検索結果は新しい注文から表示されます。ページが複数ある場合は、一覧の下部にあるページ番号で移動できます。

**【画面キャプチャ C02 をここに挿入】**

> 📷 **撮影する画面：** 注文管理の一覧  
> **撮影状態：** 検索条件を入力し、検索結果が表示された状態。条件は架空データで設定します。  
> **写す項目：** 注文番号・氏名・日付範囲・ステータスの検索欄、「検索」「クリア」ボタン、受付経路と「詳細」ボタンが見える一覧。

### 注文詳細で確認する

注文詳細では、注文番号と受付経路を最初に確認し、次の項目を見ます。

- 現在の注文状態
- 商品名、内容量、数量、単価、小計、商品合計
- お客様からのご要望
- 支払方法、送料、代引手数料、合計
- 注文者情報、お届け先情報
- 配送・送り状情報
- 注文対応履歴、管理メモ

「Web」「電話」「FAX」「店頭」「その他」などの受付経路が表示されます。Web注文も電話等の注文も、同じ注文一覧・詳細画面で確認します。

> ⚠️ **注文情報と会員情報は別です**
>
> 注文時点の氏名・住所・電話番号や商品内容は、その注文に保存されています。会員情報や商品情報を後から変更しても、過去の注文情報は自動では書き換わりません。

**【画面キャプチャ C03 をここに挿入】**

> 📷 **撮影する画面：** 注文詳細  
> **撮影状態：** 送料が入力済みで、注文商品・お客様からのご要望・支払情報を確認できるテスト注文を表示します。  
> **写す項目：** 注文番号、受付経路、現在の状態、商品明細、金額、お客様からのご要望、お客様情報への入口。長い画面は上部と下部に分け、個人情報はすべて架空データにします。

## 3. 電話・FAX・店頭などの注文を登録する

注文登録には途中確認画面がありません。「注文を登録」を押すと、その時点で注文が作成されます。登録前に入力内容を見直してください。

### 登録手順

1. 「注文管理」を開き、「注文を登録」を押します。
2. 「注文経路」で、実際に注文を受けた方法を選びます。
3. 「注文商品」で商品を入力します。
   - 商品が一覧にある場合：「商品を選択」を押し、商品を選びます。
   - 一覧にない商品を登録する場合：商品名などを直接入力します。
   - 2種類以上の商品を登録する場合：「商品を追加」を押して明細を増やします。
4. 明細ごとに、商品名、必要に応じて内容量、単価、数量、税率を入力します。
5. 「注文者情報」に注文した方の氏名、郵便番号、住所、電話番号を入力します。メールアドレスは任意です。
6. 「お届け先情報」に届け先を入力します。
   - 注文者と届け先が同じ場合は「注文者情報をコピー」を押せます。コピーした後、内容が正しいか確認します。
   - 顧客台帳に登録済みの場合は「顧客台帳から選択」から転記できます。転記後も注文内容と照らし合わせます。
7. 「お支払い方法」を選びます。
8. 必要な場合だけ「管理メモ」に店舗内の対応事項を入力します。
9. 画面を上から下まで見直し、注文経路、商品、数量、単価、注文者、お届け先、支払方法が正しいことを確認します。
10. 「注文を登録」を押します。
11. 注文詳細が表示されたら、受付経路、商品明細、商品合計、注文者、お届け先、支払方法をもう一度確認します。新しい注文の状態は「受付」です。

**【画面キャプチャ C04 をここに挿入】**

> 📷 **撮影する画面：** 注文登録フォーム（上部・下部の2枚）  
> **撮影状態：** 1件の商品を入力し、架空の注文者・お届け先・支払方法を入れた登録前の状態。  
> **写す項目：** 上部は注文経路、商品選択、商品名・単価・数量・税率。下部は注文者・お届け先、顧客台帳選択、注文者情報コピー、支払方法、管理メモ、「注文を登録」ボタン。実在する氏名や連絡先を使わないでください。

### 入力時の注意

- 商品明細は1件以上必要です。数量は1以上の整数です。
- 商品単価は税込金額で入力します。画面に表示された税率も確認します。
- 商品選択後に商品名・単価などを変更すると、商品マスタと異なる内容の明細として保存されることがあります。注文書やお客様への確認内容に合わせて入力してください。
- 注文登録画面では送料・代引手数料を入力しません。注文作成後、注文詳細で入力します。
- 顧客台帳の情報は注文登録後に自動反映されることがあります。既存台帳の住所・電話・メモが自動更新されるとは限らないため、注文フォームに転記された情報を必ず確認してください。

> ⚠️ **登録ボタンを押す前に**
>
> 注文を二重に登録しないよう、すでに同じ注文が一覧にないか確認してください。誤って登録した場合は、自己判断で新しい注文を作り直さず、注文詳細で状態を確認して管理担当者に連絡してください。

## 4. 商品を登録・編集する

### 商品一覧で探す

1. 管理メニューの「商品管理」を選びます。
2. 商品名を入力するか、「公開状態」を選びます。
3. 「検索」を押します。条件を消す場合は「クリア」を押します。
4. 対象商品の「編集」を押します。

**【画面キャプチャ C05 をここに挿入】**

> 📷 **撮影する画面：** 商品管理の一覧  
> **撮影状態：** 公開中と非公開の商品が少なくとも1件ずつ検索結果に表示された状態。  
> **写す項目：** 商品名検索欄、公開状態の選択、「検索」「クリア」、商品名・価格・公開状態、編集ボタン。

### 商品を新しく登録する

1. 商品一覧で「商品を登録」を押します。
2. 次の項目を入力します。

| 項目 | 入力・選択内容 |
| --- | --- |
| 商品名 | お客様に表示する商品名 |
| 分類 | 選択肢から選びます |
| 内容量 | 例：500g |
| 価格（税込） | 税込の金額を整数で入力します |
| 消費税率 | 商品に適用する税率を選びます |
| 公開状態 | 公開する場合は「公開中」、掲載しない場合は「非公開」 |
| 定番商品 | 定番として表示する場合にチェックします |
| 商品説明 | 必要に応じて商品の説明を入力します |
| 商品画像 | 必要に応じてJPEG・PNG・WebP形式の画像ファイルを選びます（最大5MB） |

3. 入力内容と公開状態を確認します。
4. 「商品を登録」を押します。
5. 商品一覧に戻ったら、商品名・価格・公開状態が登録した内容になっているか確認します。

**【画面キャプチャ C06 をここに挿入】**

> 📷 **撮影する画面：** 商品登録フォーム  
> **撮影状態：** 入力前か、架空の商品情報を入力した状態。公開状態と税率の選択肢が判読できるようにします。  
> **写す項目：** 商品名、分類、内容量、価格（税込）、消費税率、公開状態、定番商品、商品説明、画像選択欄と形式・容量の案内、「商品を登録」ボタン。実在の販売価格や未承認の商品情報は使わないでください。

### 登録済み商品を変更する

1. 商品一覧から対象商品の「編集」を押します。
2. 変更する項目を入力し直します。
3. 商品画像を変更する場合は、新しい画像を選びます。画像を消すだけの場合は「現在の画像を削除する」にチェックします。新しい画像を選んだ場合は、削除チェックより画像の差し替えが優先されます。
4. 「変更を保存」を押します。
5. 画面に成功メッセージが表示され、入力内容が更新されたことを確認します。

**【画面キャプチャ C07 をここに挿入】**

> 📷 **撮影する画面：** 商品編集フォーム  
> **撮影状態：** 架空の商品画像が登録済みで、公開状態と画像操作欄が見える状態。必要なら「現在の画像を削除する」の選択例を別画像にします。  
> **写す項目：** 現在の画像、画像変更欄、画像削除チェック、公開状態、価格、税率、「変更を保存」ボタン。画像の差し替えと削除の違いが分かるようにします。

公開中の商品は購入者向けサイトに表示されます。非公開にすると商品一覧から表示されなくなります。保存前に、商品名・価格・税率・公開状態をよく確認してください。

### 商品の削除

商品編集画面の下部にある「商品を削除」を押すと確認画面が表示されます。削除すると商品一覧・購入者向けの商品表示から除外されます。過去の注文記録は残ります。削除前に対象商品名を確認し、必要な場合は管理担当者に確認してください。

**【画面キャプチャ C08 をここに挿入】**

> 📷 **撮影する画面：** 商品削除の確認ダイアログ  
> **撮影状態：** 削除ボタンを押した後、最終確定する前の状態。  
> **写す項目：** 削除対象の商品名、削除後に商品一覧から表示されなくなる説明、「キャンセル」「削除する」ボタン。誤操作防止の注意を添えます。

> ⚠️ 画面には削除した商品の復元操作がありません。誤って削除した場合は、同じ商品をすぐ登録し直す前に管理担当者に相談してください。

> 📌 **管理担当者に確認してから公開・変更する項目**
>
> 商品の公開判断、販売価格、税率、画像や説明文の承認ルールは、画面では決まりません。店舗内で確認された内容を入力してください。

## 5. 注文内容・注文者・お届け先を編集する

### 編集できる状態

| 注文状態 | 注文内容・お客様情報 |
| --- | --- |
| 受付 | 編集できます |
| 入金待ち | 編集できますが、注意メッセージが表示されます |
| 発送準備中 | 編集できますが、注意メッセージが表示されます |
| 発送済 | 編集できません |
| キャンセル | 編集できません |

入金待ち・発送準備中では、すでにお客様へ金額を伝えている可能性があります。金額を変更する場合は、必ず変更前に管理担当者へ確認してください。

### 商品明細を編集する

1. 注文詳細を開き、「明細を編集」を押します。
2. 商品名、内容量、単価、数量、税率を確認します。
3. 変更する項目を入力します。
   - 行を増やす場合は明細追加の操作を使います。
   - 行を削除する場合は、その明細の削除操作を使います。
4. 合計金額を確認し、「変更を保存」を押します。
5. 注文詳細に戻ったら、明細と商品合計、消費税内訳が意図どおりか確認します。

**【画面キャプチャ C09 をここに挿入】**

> 📷 **撮影する画面：** 注文明細の編集画面  
> **撮影状態：** 架空注文の明細が1～2行表示された状態。  
> **写す項目：** 商品選択または直接入力欄、単価・数量・税率、明細追加・削除の操作、「変更を保存」ボタン。個人情報は写さず、保存すると注文金額が変わる注意を付けます。

### 注文者・お届け先を編集する

1. 注文詳細の「お客様情報を編集」を押します。
2. 注文者情報とお届け先情報を、それぞれ確認して修正します。
3. 同じ住所にする場合は「注文者情報をコピー」を押し、コピー後の全項目を確認します。
4. 「変更を保存」を押します。
5. 注文詳細に戻り、注文者・お届け先の氏名、郵便番号、住所、電話番号を確認します。

**【画面キャプチャ C10 をここに挿入】**

> 📷 **撮影する画面：** 注文者・お届け先の編集画面  
> **撮影状態：** 注文者と異なる届け先を架空データで入力した状態。画面上部の変更注意が表示される状態が望ましいです。  
> **写す項目：** 注文者とお届け先が別欄で表示されること、「注文者情報をコピー」、「変更を保存」ボタン。氏名・住所・電話・メールは架空データにします。

注文者メールアドレスは任意項目です。注文者情報を変更しても、顧客台帳やWEB会員情報が同時に変更されるわけではありません。

### お客様からのご要望と管理メモ

- 「お客様からのご要望」は注文時に記録された内容です。注文後は編集できません。
- 「管理メモ」は店舗内向けの記録です。入力欄を変更して別の場所をクリックすると保存され、「保存しました」と表示されます。
- 「保存に失敗しました」と表示された場合は、画面を閉じたり移動したりせず、内容を控えて管理担当者に連絡してください。

## 6. 送料・代引手数料を入力する

1. 対象の注文詳細を開きます。
2. 「お支払い・ご請求金額」の「送料・手数料を編集」を押します。
3. 「送料（税込）」に注文全体の送料を入力します。複数口であっても、送料欄には注文全体の金額を入力します。
4. 代金引換の場合は「代引手数料（税込）」も入力します。
5. 金額と注文番号を確認し、「変更を保存」を押します。
6. 注文詳細で送料・手数料・合計金額・未確定の表示を確認します。

入力欄の意味は次のとおりです。

| 入力 | 画面上の意味 |
| --- | --- |
| 空欄 | まだ金額が決まっていない |
| 0 | 金額が確定しており、0円 |
| 1以上の整数 | 確定した税込金額 |

空欄のままだと金額は未確定です。送料を確定すると、受付から次の状態へ進める条件の一つを満たします。代金引換の場合は、送料と代引手数料の両方が確定している必要があります。

> ⚠️ **金額を推測して入力しないでください**
>
> 送料・代引手数料の金額表はこの画面にありません。店舗で確認された金額が分からない場合は、入力せずに管理担当者へ確認してください。0円を入力すると「無料で確定」として扱われます。

入金待ちまたは発送準備中の注文で金額を変更するときは、お客様への案内内容と一致しているか、先に管理担当者へ確認してください。

**【画面キャプチャ C11 をここに挿入】**

> 📷 **撮影する画面：** 送料・手数料の編集ダイアログ  
> **撮影状態：** 代金引換のテスト注文で、送料と代引手数料の欄が両方表示された状態。説明用には架空の金額を入力するか、入力前の空欄状態を使います。  
> **写す項目：** 送料（税込）、代引手数料（税込）、未確定の場合は空欄にできる説明、「変更を保存」ボタン。金額は実運用の料金表と誤解されないよう「例」と明記します。

## 7. 注文の状態を進める・キャンセルする

### 注文状態の流れ

画面の「現在のステータス」と次の状態を確認します。

| 支払方法・現在の状態 | 次の状態 | 画面で進めるために必要なこと |
| --- | --- | --- |
| 銀行振込・受付 | 入金待ち | 送料が確定していること |
| 代金引換・受付 | 発送準備中 | 送料と代引手数料が確定していること |
| 店頭支払・受付 | 発送準備中 | 送料が確定していること |
| 入金待ち | 発送準備中 | 入金を確認してから操作します |
| 発送準備中 | 発送済 | 1個口以上あり、すべての個口に送り状番号があること |

### 状態を進める

1. 注文詳細を開き、注文番号・支払方法・現在の状態を確認します。
2. 画面に表示される次の状態へ進むボタンを押します。
3. 表示された確認画面で、状態が正しいことを確認します。
4. 「お客様への連絡方法」を選びます。
   - メール送信を選べる場合、選択すると注文者へメールを送信する処理が行われます。
   - 電話・FAX・対面で連絡済みの場合は、該当する方法を選びます。
   - 連絡が不要の場合は「連絡不要」を選びます。
5. 必要な場合は「対応メモ」に、連絡内容や確認内容を入力します。
6. 内容を確認し、「ステータスを進める」を押します。
7. 注文詳細に戻ったら、表示中の状態と注文対応履歴を確認します。

「入金待ち」から進めるボタンには、入金を確認してから更新するよう案内が表示されます。入金を確認せずに進めないでください。

**【画面キャプチャ C12 をここに挿入】**

> 📷 **撮影する画面：** ステータス更新の確認ダイアログ  
> **撮影状態：** 次の状態へ進める操作を押した後、更新確定前。メール送信が選べる状態と、電話・連絡不要などの選択肢が見える状態を撮影します。  
> **写す項目：** 注文番号、変更前後の状態、連絡方法、対応メモ、「ステータスを進める」ボタン。入金待ちからの遷移では「入金を確認してから更新」の案内も写します。架空注文を使用します。

> ⚠️ **メール連絡について**
>
> メールを選ぶと自動送信処理が実行される場合があります。相手先・メールアドレス・連絡内容を確認してから選んでください。実際にメールが届くかはメール設定にもよります。届いたか分からない場合は、再送を繰り返さず管理担当者へ確認してください。

### 注文をキャンセルする

1. 注文詳細の下部にある「この注文をキャンセル」を押します。
2. 注文番号を確認します。
3. 連絡方法を選び、必要なら対応メモを入力します。
4. 注文をキャンセルしてよいことを確認し、「注文をキャンセルする」を押します。
5. 注文詳細で状態が「キャンセル」になったことを確認します。

**【画面キャプチャ C13 をここに挿入】**

> 📷 **撮影する画面：** 注文キャンセルの確認ダイアログ  
> **撮影状態：** 注文詳細からキャンセル操作を開いた後、確定前。  
> **写す項目：** 対象注文番号、キャンセル後は編集・状態変更できない注意、連絡方法、対応メモ、「注文をキャンセルする」ボタン。スタッフが確定前に立ち止まれるよう、ボタン周辺を含めて撮影します。

> ⚠️ **キャンセルは取り消せません**
>
> キャンセル後は注文内容・お客様情報・状態を変更できません。発送済みの注文はキャンセルできません。キャンセルするか迷う場合や誤ってキャンセルした場合は、管理担当者へ連絡してください。

### 支払方法を変更する

「お支払い方法を変更」は、注文が「受付」の間だけ使えます。注文詳細で現在の支払方法を確認し、変更後も正しいことを再確認してください。変更により代引手数料が未確定または0円に切り替わる場合があります。送料・手数料を再確認してください。

## 8. 送り状番号と複数口を登録する

1. 注文詳細の「配送・送り状情報」を開き、「送り状情報を編集」を押します。
2. すでに入力欄が表示されている場合は、個口ごとに送り状番号を入力します。入力欄がない場合は「個口を追加」を押して欄を作ります。
3. 複数口の場合は「個口を追加」を必要な回数押し、個口ごとの番号を入力します。
4. 入力した番号と個口数を、手元の送り状と照らし合わせます。
5. 「変更を保存」を押します。
6. 注文詳細に戻り、個口ごとの番号が表示されていることを確認します。番号の横に「配送状況を確認」が出る場合はリンクを開いて確認できます。

発送済みにするには、個口を1件以上登録し、すべての個口に送り状番号を入力しておく必要があります。番号が空欄の個口があると、発送済みにできません。

- 発送済みになった後でも、送り状番号の訂正はできます。
- キャンセル済みの注文では送り状情報を編集できません。
- 個口の行を削除して保存すると、その個口の登録自体が削除されます。番号だけを一時的に未確定にしたい場合は、削除せず番号欄を空欄にします。
- 送り状番号は手入力です。送り状の情報が自動で取り込まれる機能はありません。

**【画面キャプチャ C14 をここに挿入】**

> 📷 **撮影する画面：** 送り状情報の編集ダイアログ  
> **撮影状態：** 2個口の入力欄を表示し、両方にテスト用番号を入力した状態。番号が未発行の例を示す場合は、別画像で空欄の個口を撮影します。  
> **写す項目：** 個口ごとの送り状番号欄、「個口を追加」「削除」「変更を保存」ボタン。実在する配送伝票番号は使わず、テスト番号を使います。

## 11. 困ったときの確認

| 困ったこと | まず確認すること |
| --- | --- |
| 注文が見つからない | 注文番号、氏名の入力、日付範囲、ステータスを確認し、「クリア」後に検索します |
| 注文を次の状態へ進められない | 画面に表示される注意を読みます。受付では送料、代引では代引手数料、発送済みにするときは全個口の送り状番号が必要です |
| 入金待ちから先へ進められない | 入金を確認してから操作します。入金確認の方法が不明なら管理担当者に確認します |
| 保存時に入力エラーが出る | 赤字の案内を読み、必須項目、金額、数量、日付、選択内容を確認して再入力します |
| 送料・代引手数料が分からない | 推測で入力せず、管理担当者に確認します |
| 管理メモが保存されない | 「保存に失敗しました」の表示を確認し、入力内容を控えて管理担当者に連絡します |
| 商品・顧客を誤って削除した | 同じデータをすぐ作り直さず、対象名と操作内容を管理担当者へ連絡します |
| メールが送信されたか分からない | 送信操作を繰り返さず、注文詳細と管理担当者に確認します |
| 画面が説明と違う | 操作を止め、画面名と表示されているメッセージを管理担当者に伝えます |

## 12. 画面画像について

本文中の「【画面キャプチャ C01～C19 をここに挿入】」は、画像を貼り付ける位置です。各位置の「撮影する画面」「撮影状態」「写す項目」に合わせて撮影してください。現時点では画像を作成・掲載していません。

- 実際の管理画面を撮影し、画面の説明と撮影時の表示が一致していることを確認します。
- 実在のお客様の氏名・住所・電話番号・メールアドレス・注文番号や、本物の送り状番号を写さないでください。テスト用の架空データを使います。
- 金額の例を載せる場合は、店舗の実際の送料・手数料と誤解されないよう「例」と明記します。
- ボタン名や入力欄が読める大きさで切り出します。画像内にパスワードやログイン情報を写さないでください。
